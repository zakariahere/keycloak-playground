Six things that bit us building this lab

  • docker compose down without -v does not re-import the realm. The strategy is IGNORE_EXISTING, so edits to the JSON are silently skipped.
  • postgres:18+ wants the volume at /var/lib/postgresql, not /data. The old path makes the image refuse to boot.
  • The Keycloak image ships no curl and no wget. Healthchecks have to use bash /dev/tcp.
  • Spring Boot 4 moved RestClient.Builder out of the web starter into spring-boot-starter-restclient.
  • Initializr's legacy metadata reports 4.1.0.RELEASE; the real Maven artifact is 4.1.0.
  • issuer-uri is fetched eagerly at startup — the app will not boot with Keycloak down. Tests must spell the endpoints out instead.
Five of these six fail with a message that points somewhere other than the cause. That is the real tax on this stack.
