WHY HASH THE NONCE AT ALL

Keycloak copies the hashed nonce into the ID token, and ID tokens get handled, logged, sometimes forwarded. Whoever sees one learns the hash and never the raw value, so they cannot forge a request that would validate against it.

Two parameters, one pattern: send a hash, keep the thing that made it, prove ownership later. Once you see the shape you find it everywhere in OAuth.
