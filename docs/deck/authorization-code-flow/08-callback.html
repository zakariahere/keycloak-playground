07When the code comes back

Five checks between the code and a token

  1. OAuth2LoginAuthenticationFilter takes the returned state and looks up the saved request in the session — and removes it. One use only.
  2. No match, no flow. That is the CSRF check, and it is the whole reason state exists.
  3. Your server opens a back-channel POST carrying code, redirect_uri, client_id, client_secret and code_verifier.
  4. Keycloak checks all five: code unused, redirect URI byte-identical to the original, secret correct, and sha256(verifier) == challenge.
  5. Tokens come back. Spring then validates the ID token: signature, issuer, audience, expiry, and nonce == sha256(stored nonce).
Step 3 is the only one the browser never sees — and it is the only one carrying secrets.
