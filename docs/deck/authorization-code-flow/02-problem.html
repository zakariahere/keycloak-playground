01The problem

Your app needs a token. It must never see the password.

alice → Keycloak → a single-use code → your app → token
WHO TAKES THE PASSWORD

Keycloak. Your app renders no login form and never receives a credential it could store, log, or leak.

WHAT CROSSES THE BROWSER

A code. Short-lived, single-use, and worthless without two secrets that never leave your server.

The whole flow exists to move a credential from Keycloak to your server without routing it through the browser.
