THE TRICK

/flow resolves a request with the same resolver the redirect filter uses, then renders it instead of redirecting.

WHY IT IS SAFE TO OPEN

It saves nothing. The real flow stores state, nonce and verifier in the session; this page does not, so it never breaks a login in another tab.

git switch 001_authorization_code_flow && ./mvnw spring-boot:run
# http://localhost:8090/flow -- reload it, watch all three values change
Borrow the framework's own component and you get the real artefact. Rebuild the URL by hand and you only verify your own assumptions.
